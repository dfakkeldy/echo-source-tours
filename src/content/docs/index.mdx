These tours walk through real subsystems of **Echo**, an open-source audiobook study
player for iOS, watchOS, and macOS. Each tour snapshots the actual source at a known
commit and explains it block by block.

<Aside title="Snapshot from June 2026">
  All tours are pinned to the June 2026 Echo source, commit
  [`c5807ec`](https://github.com/dfakkeldy/Echo/commit/c5807ec). Echo has kept changing since,
  so some files, names and details may differ from the current code.
</Aside>
